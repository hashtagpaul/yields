# Yields — In brick we trust

Un jeu sérieux sur la gestion d’un fonds immobilier, en quatre séances : la thèse d’investissement, la carte, le portefeuille, le conseil du fonds.
A serious game about running a real estate fund, in four sessions: the investment thesis, the map, the portfolio, the fund board.

**Jouer · Play :** https://hashtagpaul.github.io/yields/

Ce dépôt ne contient que la version publiée du jeu (`index.html`, protégée). Le code source n’est pas public.
This repository only holds the published, protected build of the game (`index.html`). The source code is not public.
